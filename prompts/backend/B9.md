## Resumen de Cambios

1. **Dependencia `springdoc-openapi` (`backend/pom.xml`):**
   - Se incorporó `org.springdoc:springdoc-openapi-starter-webmvc-ui:2.8.6`, versión compatible con Spring Boot 3.5.16 y Spring Framework 6.2.

2. **Configuración OpenAPI 3 y esquema JWT (`OpenApiConfig.java`):**
   - Se definió el bean `OpenAPI` con título, versión `1.0.0`, guía paso a paso para el jurado con las credenciales de demostración (`admin1`/`admin123` y `operador1`/`cacao123`) y el esquema de seguridad HTTP Bearer JWT (`bearerAuth`).

3. **Documentación de controladores (`backend/src/main/java/co/edu/usco/cacao/web/*.java`):**
   - Se añadieron etiquetas `@Tag` organizadas por dominio funcional (Autenticación, Ficha Pública, Configuración y Catálogos, Lotes/Trazabilidad/Recall, Transformaciones/Balance, y Alertas/Auditoría/CSV) y resúmenes `@Operation` indicando el rol requerido en cada endpoint (`[Público]`, `[OPERADOR / ADMINISTRADOR]`, `[Solo ADMINISTRADOR]`), además de `@SecurityRequirements` vacío en los endpoints públicos (`POST /api/auth/login` y `GET /api/public/ficha/{codigo}`).

4. **Pruebas de integración (`OpenApiDocumentacionTest.java`):**
   - Se implementó `co.edu.usco.cacao.web.OpenApiDocumentacionTest` con `@PruebaIntegracion` sobre `cacao_test` verificando que `GET /v3/api-docs` y `GET /swagger-ui/index.html` responden `200 OK` sin autenticación y exponen el esquema JWT junto con todas las rutas del contrato técnico.
