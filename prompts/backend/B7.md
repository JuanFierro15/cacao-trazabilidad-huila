## Archivos Creados

1. `datos/scripts/verificar_integridad.sql`:
   - Sección 1: Conteos de tablas (`total_lotes`, `lotes_recepcion`, `lotes_derivados`, `total_transformaciones`, `total_composiciones`, `total_alertas`, `total_auditoria`, `total_usuarios`).
   - Sección 2: Balance global de masa en inventario (`suma_recibida_kg`, `suma_consumida_kg`, `suma_disponible_kg`, `discrepancia_kg = recibida - (consumida + disponible)`).
   - Sección 3: Inconsistencias individuales de inventario donde `cantidad_disponible <> cantidad_recibida - cantidad_consumida` o `cantidad_disponible < 0` (debe ser 0 filas).
   - Sección 4: Lista ordenada de lotes por código ascendente con detalles y estado.

2. `datos/scripts/respaldar.ps1`:
   - Detección automática: verifica si el servicio `db` de Docker Compose está activo (`docker compose ps --services --filter "status=running"`). Si está activo usa `docker compose exec -T db pg_dump -U cacao -d cacao -Fc -f /datos/respaldos/...`.
   - Si no está activo (Modo Local): carga variables de entorno desde `.env` (`DB_HOST`, `DB_PORT`, `POSTGRES_USER`, `POSTGRES_DB`, `POSTGRES_PASSWORD`).
   - Agrega binarios de PostgreSQL al `$env:PATH` (`C:\Program Files\PostgreSQL\*\bin`) en caso de no encontrarse.
   - Ejecuta `pg_dump -Fc -f <ruta>` de manera nativa sin redirección `>` (evitando corrupción de bytes por codificación de texto en PowerShell).

3. `datos/scripts/respaldar.sh`:
   - Equivalente Bash para entornos Linux / macOS / WSL / CI con la misma autodetección de Docker vs Local, flags `-Fc -f` y lectura de `.env`.

4. `datos/scripts/restaurar.ps1`:
   - Acepta ruta de archivo o toma automáticamente el archivo `.dump` más reciente en `datos/respaldos/`.
   - Ejecuta verificación de integridad previa (**ESTADO ANTES**) invocando `verificar_integridad.sql`.
   - Termina conexiones activas y reinicia la base de datos limpiamente: `DROP DATABASE IF EXISTS cacao WITH (FORCE); CREATE DATABASE cacao;`.
   - Ejecuta restauración con `pg_restore "--no-owner"`.
   - Ejecuta verificación de integridad posterior (**ESTADO DESPUÉS**) y valida que los balances cuadren.

5. `datos/scripts/restaurar.sh`:
   - Equivalente Bash para entornos UNIX / WSL con verificación antes y después, `DROP DATABASE ... WITH (FORCE)`, y `pg_restore --no-owner`.
